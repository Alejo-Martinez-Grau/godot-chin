WIP:

The game consists of playing cards that are above or below the rank of the pool cards.

Use the QWER keys to highlight a card and the Left or Right arrows to play it.

Press the Up arrow key to draw a new card.

Press the space bar to call “Spit” when both cards in the pool have the same rank. If a player correctly calls “Spit,” the opponents must grab all the cards in the pool.

The player who empties their hand and deck first wins.
